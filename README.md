## 🧑‍💻 Architecting Scalable Solutions

Hello! I'm a Full-Stack Software Engineer specializing in deploying robust web platforms and high-performance mobile applications. I focus on building decoupled systems with high availability, leveraging modern runtimes and type-safe architectures.

- 🎯 **Focus Areas:** Designing **Microservices Architecture**, prioritizing ultra-low latency via the **Bun runtime**.
- 🧠 **Expertise:** Full-Stack engineering using the **MERN stack**, advanced state management (**Redux Toolkit** / **TanStack Query**), and cross-platform mobile development with **React Native**.
- ⚙️ **Data & Performance:** Proficient in **MySQL** (Relational) and **MongoDB** (NoSQL), implementing **Redis** for caching, and utilizing Bun's toolchain for optimized workflows.
- 🌱 **Currently Exploring:** Advanced DevOps, Docker orchestration, and applying **SOLID principles** to modern API design.
- ⚡ **Fun fact:** *Execution beats perfection, but Architecture ensures stability.*
